gdr1613_Inverted_1D_VelocityModel.csv is an unmodified byte copy (CRLF line endings and trailing
commas kept) of https://gdr.openei.org/files/1613/Inverted_1D_VelocityModel.csv, from:
Vera Rodriguez, I., Wolpert, J., Podrasky, D., Coleman, T., Maldaner, C., Ma, Y., Chamarczuk, M.,
Becker, M., & Ajo-Franklin, J. (2024). Utah FORGE 3-2417: DAS Microseismic Event Catalog from the
16A/16B Circulation Test, 2023 [Data set]. Geothermal Data Repository, Rice University.
https://doi.org/10.15121/2376139
License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Only the file name was changed.
test_velocity.py checks that configs/velocity/forge_1d.csv matches it.
