# Requests to H3

### REQ-H2-1 · Public-event depth comes from elevM, never CatalogEvent.depthKm
- From: H2 (reviewer on MATCH-01)
- Needed by: before public events render with a depth readout
- What: `CatalogEvent.depthKm` is the published depth, which for this catalog is km below sea level (see `depthDatum`). `SeismicEvent.depthKm` is km below `refSurfaceElevM`. Same field name, different datums. Place public events from `enu`/`elevM`, and compute any depth shown next to our events as `(refSurfaceElevM - elevM) / 1000` under the "Depth below site surface" label. If the published value is shown at all, label it "published depth, km below sea level".
- Also: ENU follows the UTM 12N grid (docs/01), so scene north is grid north. That differs from true north by the grid convergence at the origin (about a degree). Don't rotate data to true north, or everything stops lining up with the terrain and stations.
- Status: done (2d3c3ea)
